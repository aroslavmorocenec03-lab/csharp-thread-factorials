# Паралельний розрахунок факторіалів — C# Thread

Консольна програма виконує завдання на створення потоків через **`System.Threading.Thread`**.

## Запуск

Потрібен **.NET SDK 10**. Завантажте репозиторій через **Code → Download ZIP**, розпакуйте й виконайте в папці проєкту:

```powershell
dotnet build
dotnet run
```

## Виконання завдання

1. Створюється масив `int[20]`.
2. Кожен елемент отримує випадкове значення через `Random.Next(1, 13)`, тобто **від 1 до 12 включно**.
3. Для кожного елемента створюється власний об’єкт `Thread` — усього **20 робочих потоків**. Навіть однакові числа з різних елементів обробляються окремо.
4. У кожному потоці циклом обчислюється факторіал і виконується `Console.WriteLine($"факторіал числа: {num}! = {numF}")`.
5. Спочатку через `Start()` запускаються всі потоки. Потім головний потік викликає `Join()` для кожного й очікує завершення всіх обчислень та виведення.
6. Останнім рядком виводиться точно **`Розрахунок закінчено.`**

Основний код: [Program.cs](Program.cs). У ньому немає `Task`, `Task.Run` або `Parallel.For`.

Порядок рядків із факторіалами може відрізнятися від порядку елементів масиву через планування потоків. Перед створенням кожного потоку число копіюється в окрему локальну змінну `num`, тому зміна індексу циклу не впливає на результат. Для результату використано `long`; найбільший факторіал у завданні — `12! = 479001600`.

## Висновок

`Thread` дозволив створити окремий потік для кожного елемента. `Start()` запускає роботу, а `Join()` синхронізує завершення: підсумкове повідомлення з’являється лише після всіх 20 результатів.
